# Minecraft Fabric Economy Mod

FortuneCheats Addon is a server-side Minecraft Fabric economy mod with a persistent money system, a curated item shop, player-to-player payments, and occasional free shop-item gifts accompanied by particle effects. It does not modify world structures, world generation, or loot tables.

## Install

1. Install Fabric Loader for Minecraft 1.21.11 and Java 21.
2. Place the built mod JAR in the server’s `mods` folder.
3. Start the server. Players on a dedicated server do not need to install the mod.

## Use

- Run `/money` to view your balance.
- Run `/money pay <player> <amount>` to pay an online player.
- Run `/shop` to view the catalog and buy and sell prices.
- Run `/shop buy <item> <amount>` to purchase catalog items.
- Run `/shop sell <item> <amount>` to sell matching items from your inventory.
- Operators can run `/marketgift <player>` to grant an online player a random free catalog item.
- Every five minutes, each online player has an independent 20% chance to receive a random free catalog item. Gifts trigger particle effects.
